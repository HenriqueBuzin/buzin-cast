Buzin Cast 0.6.6 adds Swedish interface text and refreshes localized store screenshots. The release also corrects Amazon Appstore SDK initialization: DRM response receiver declared, Amazon SDK classes and annotations retained, and purchasing registration and license verification handled independently. Install through Amazon Appstore on a registered Fire TV Stick. No Buzin Cast login, payment or subscription is required. Verify the interactive home screen, Settings, the Default/Cinema/Presentation/Games profiles, and About. The default profile is selected initially; Diagnostics appears only after enabling advanced options. Connect a compatible sender and the Stick to the same local network with multicast/mDNS enabled, open Control Center > Screen Mirroring and select the receiver. Use your own non-DRM content, stop on the sender and reconnect. Main APK code 42 targets API 25+; compatibility APK code 40 targets API 22+. Only selected Fire TV Sticks are targeted. Germany and Austria are excluded and use a separate no-download/no-recording app. Run only one Buzin Cast edition at a time to avoid conflicts on local receiver ports. Both final production APKs were signed; the main edition was installed locally. Amazon Appstore license authorization must be checked through the store installation.
